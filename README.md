# Breakout

Versão do clássico Breakout feita em Python com Pygame. Controle a raquete, rebata a bola e quebre todas as fileiras de blocos coloridos. O placar fica no topo e há efeitos sonoros a cada rebatida e ponto.

## Arquivos

- `main.py`: o jogo inteiro (tela 600×850, 60 FPS).
- `assets/`: fonte e efeitos sonoros.

## Como rodar

```bash
pip install pygame
python main.py
```

Controles: setas ← e → movem a raquete.
